# Datasets

| Archivo | Descripción | Fuente |
|---|---|---|
| `mtcars.csv` | 32 autos (consumo, cilindros, potencia, peso…), *Motor Trend*, 1974 | Dataset clásico `mtcars` del lenguaje R |
| `flights.csv.gz` | 336.776 vuelos que salieron de Nueva York en 2013 | Paquete `nycflights13` (datos del Bureau of Transportation Statistics de EE. UU.) |
| `airlines.csv` | Nombre completo de cada aerolínea (`carrier` → `name`) | Paquete `nycflights13` |
| `airports.csv` | Aeropuertos (código FAA, nombre, latitud, longitud…) | Paquete `nycflights13` |

El dataset `diamonds` no está aquí: se carga con `sns.load_dataset("diamonds")` (librería seaborn).
